# Identidade visual do Cortaí ✂️

<p align="center"><img src="logo.svg" alt="Logo do Cortaí" width="360"></p>

## Conceito

**Cortaí** vem de "corta aí": direto, brasileiro e bem-humorado, como o próprio app. A marca é um **play cortado**, um botão de play fatiado na diagonal. É exatamente o que o Cortaí faz: pega um vídeo e corta nos melhores momentos. O acento do "í" no logotipo é desenhado como o mesmo corte, no mesmo ângulo.

## Arquivos

| Arquivo | Uso |
|---|---|
| [`logo.svg`](logo.svg) | Logo horizontal para fundos claros |
| [`logo-light.svg`](logo-light.svg) | Logo horizontal para fundos escuros |
| [`logo-mark.svg`](logo-mark.svg) | Só a marca (ícone do app, favicon, avatar) |
| [`banner.svg`](banner.svg) | Capa do README e redes sociais |

Todos os textos estão convertidos em curvas: os arquivos funcionam em qualquer lugar, sem precisar das fontes instaladas.

## Paleta

| Nome | Hex | Uso |
|---|---|---|
| **Caju** | `#FF6A2B` | Cor principal: marca, botões, destaques |
| **Tinta** | `#16140F` | Texto e ícones sobre o Caju |
| **Mar** | `#12B5A6` | Destaque secundário |
| **Sol** | `#FFC93C` | Realces, legendas, detalhes |
| **Noite** | `#111113` | Fundo do tema escuro |
| **Areia** | `#FBF7F2` | Fundo do tema claro |

Texto sobre o Caju é sempre em **Tinta** (contraste 6,4:1), nunca em branco.

## Tipografia

- **Bricolage Grotesque** (ExtraBold 800): logotipo e títulos, com espaçamento levemente fechado.
- **DM Sans** (400, 500, 700): textos e interface.

Ambas são gratuitas (licença SIL Open Font License) e estão no Google Fonts.

## Uso da marca

- Mantenha uma área livre em volta do logo de pelo menos metade da altura da marca.
- Não mude as cores, não distorça e não aplique efeitos (sombra, contorno, gradiente) sobre o logo.
- Em tamanhos pequenos (abaixo de 32 px), use só a marca (`logo-mark.svg`).
- Os arquivos da marca seguem a licença do projeto (GPL-3.0). Se você publicar um fork modificado, prefira outro nome e outra marca para não confundir com o projeto oficial.
